# Overland

Original-IP top-down adventure for desktop Windows.  
**Engine locked: Godot 4.x, C# only.**  
Pixel-art, 16:9, top-down orthogonal camera.

Working title for the first ship: **Overland Slice 0**.  
First place: **Kilnwalk**. First dungeon: **the Cold Stack**.
